# Sistema de Gestión de Despachos Textiles

Sistema completo para gestión de despachos en la industria textil, con control de inventario, cálculo de pesos y generación de reportes profesionales.

## Características principales

- 🚀 Gestión completa de clientes y artículos
- 📦 Cálculo preciso de pesos por bulto
- 📊 Exportación a Excel con formato profesional
- 🔍 Búsqueda avanzada de productos
- 📝 Generación automática de guías de despacho
- 📝 Generación de reportes diarios de despachos

## Requisitos del sistema

- Python 3.8+
- Dependencias: pandas, openpyxl, tkinter

## Instalación

Instalación básica: 

1- abrir consola CMD 

2- buscar la ruta de la carpeta donde esta alojado el programa C:\Users\user\.vscode\carpetadestino y colocar el codigo en el cmd 

3- Utilizar el comando: pyinstaller --onefile --windowed Sistema_de_despachos.py, para ejecutarlo en el CMD y asi generar la aplicacion (IMPORTANTE: tener las librerias y python instalado como indica los requisitos).
